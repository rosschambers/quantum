Layout

Off: unified scrolls sideways; split clips each side (real build would sync-scroll).
qv opens at 900 wide. Drag to see where split stops being readable.

Staging (review = stage)

Sections: a file staged and then edited again (partially staged) shows in BOTH (new edits under Unstaged, the staged part under Staged). One list: a single entry with an "unstaged changes" toggle.
After "Simulate agent edit", try staging highlighter.ts before refreshing: qv refuses to stage content you have not seen. Keys work in the preview: n / p, ] / [, s, R.

Multi-file navigation

Click files in the sidebar and file headers (collapse) inside the preview.

Highlighting

Whole old and new files are tokenized, not hunk fragments, so block comments and strings color correctly.
Theme tokens = --color-accent / --color-error (follows theme switches). highlight-theme = the unused .hljs-addition/.hljs-deletion colors.

Gutter

Context

Click a collapsed region in the preview to expand it.
Gutter strip runs the full height of the expanded lines, so it never scrolls away. Expand a region, then hover the left edge.

Copy

"Hidden lines too" gives a contiguous piece of the real file. "Only visible" pastes with a silent hole where the region was.
Always: line numbers, signs, region labels, headers, and split-view filler are never selected or copied. In split view a selection stays on the side it started on. Select text in the preview and press Ctrl+C to see exactly what lands on the clipboard.
